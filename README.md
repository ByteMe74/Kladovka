# Кладовка

Складской учёт на телефоне: вещи, контейнеры, полки, стеллажи и кладовки, с
фотографиями и синхронизацией между телефоном, компьютером и сервером.

Работает на Android и Windows. Данные хранятся на своём сервере, а не в чужом
облаке: `https://kladovka.dr6ter.ru`.

## Что это

Обычный список вещей, у которого есть место. Не «заметки», а адрес: этаж →
стеллаж → полка → контейнер → вещь. Каждая вещь помнит, где лежит, поэтому её
можно найти, не перебирая шкафы.

- **Места** — контейнер (ящик, коробка), полка, стеллаж, кладовая. Вложенность
  любой глубины.
- **Вещи** — название, количество, единица измерения, категория, заметка,
  фотография, координаты места.
- **Синхронизация** — телефон и компьютер обмениваются данными с сервером.
  Можно работать без сети: изменения накопятся и уйдут при следующей синхронизации.
- **Фотографии** — снимаются камерой или берутся из галереи. Одинаковые снимки
  не хранятся дважды.
- **Общий доступ** — можно открыть другому человеку конкретное место.
- **Резервная копия** — выгрузка и загрузка файлом, без программы.

## Установка

### Android

Скачайте APK с [kladovka.dr6ter.ru](https://kladovka.dr6ter.ru/) и поставьте
на телефон. Если Android откажет в установке, а на телефоне уже стоит версия
1.46 или старше, прочитайте предупреждение на сайте: ключ подписи сменился, и
обновиться поверх старой версии нельзя, нужен безопасный переход через
веб-кабинет.

### Windows

Скачайте `Kladovka.exe` — это один файл, Java на компьютере не нужна.

Windows может показать синий щиток «защитил ваш компьютер». Это не опасный
файл: причина в том, что издатель программы Windows не знаком, а подпись
самоподписанная. Нажмите «Подробнее» → «Выполнить в любом случае». Подробности
и объяснение — [на сайте](https://kladovka.dr6ter.ru/).

## Сборка из исходников

Нужны JDK 21 и Android SDK (путь в `android/local.properties`). Подробности,
включая ключ подписи и сборку одного `.exe`, — в [BUILD.md](BUILD.md).

```powershell
# Android
cd android
.\gradlew.bat :app:assembleRelease

# Windows, одним файлом
cd desktop
.\gradlew.bat singleExe
```

Пароль ключа подписи Android лежит в `~/.gradle/gradle.properties`, а не в
репозитории. Пересоздавать ключ нельзя: новая подпись ломает обновление у всех,
кто уже поставил приложение.

## Структура

| Папка | Что внутри |
|---|---|
| `android/` | приложение на Kotlin и Jetpack Compose |
| `desktop/` | приложение на Compose Desktop, лаунчер на Rust |
| `docs/ops/` | серверные скрипты: бэкап, монитор, сборщик фото, доверие подписи |
| `index.php`, `api.php`, `cabinet-index.php` | сайт и серверная часть |

Резервные копии, мониторинг и восстановление описаны в [BACKUP.md](BACKUP.md).
План развития — в [ROADMAP.md](ROADMAP.md).
