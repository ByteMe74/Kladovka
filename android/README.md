# 📦 Кладовка — учёт вещей в кладовке

## Установка APK на телефон

### Способ 1: Прямо с компьютера (USB)

1. Подключите телефон к компьютеру USB-кабелем.
2. На телефоне в **Настройки → О телефоне** нажмите 7 раз на «Номер сборки» (чтобы включить режим разработчика).
3. В **Настройки → Для разработчиков** включите «Отладка по USB».
4. На компьютере откройте терминал и выполните:
   ```
   adb install -r kladovka-v1.2.apk
   ```
5. Приложение появится на главном экране.

### Способ 2: Перекинуть на телефон

1. Отправьте файл `kladovka-v1.2.apk` на телефон (через Telegram, USB, почту, Bluetooth и т.д.).
2. На телефоне откройте файл. Если система попросит, разрешите установку из «неизвестных источников».
3. Нажмите «Установить».

### Способ 3: Загрузить через браузер

Загрузите APK на любой простой хостинг (например, через `adb push` на локальный сервер) и откройте ссылку в браузере телефона.

## Как пользоваться

### Вещи
- **Добавить вещь** → нажмите **«+ Вещь»** внизу.
- Заполните: название, количество, единицу (шт, кг, м и т.д.), категорию и заметки.
- **Фото**: можно сфотографировать прямо сейчас или выбрать из галереи.
- **Где лежит**: нажмите кнопку «Место» и выберите:
  - В контейнере (на каком стеллаже)
  - Прямо на стеллаже
  - Без места
- **Территория** (необязательно): нажмите «Территория» и привяжите вещь к месту (например, «Кладовая»).
- **Поиск**: вводите название, категорию или заметку — список фильтруется мгновенно.

### Стеллажи и контейнеры (вкладка «Стеллажи»)
- Перейдите на вкладку **«Стеллажи»** внизу.
- Нажмите **«+ Стеллаж»** или **«+ Контейнер»** (кнопка на вкладке «Контейнеры»).
- Стеллажу и контейнеру можно назначить **место** (см. ниже).
- На вкладке «Стеллажи» видна вся иерархия: стеллаж → контейнеры → вещи.

### Места (вкладка «Места»)
- Отдельная вкладка **«Места»** — это список помещений/территорий: «Кладовая», «Балкон», «Гараж», «Подвал» и т.д.
- Нажмите **«+ Место»**, укажите название.
- **Карта**: нажмите «Указать на карте» — откроется карта, коснитесь нужной точки, координаты (широта/долгота) подставятся автоматически. Можно ввести координаты и вручную.
- Места назначаются **опционально**: стеллажу (в «Стеллаж»), контейнеру (в «Контейнер»), вещи (в «Вещь» → «Территория»).
- При удалении места стеллажи, контейнеры и вещи остаются, но теряют привязку к месту.

### Обновление
- Все данные (вещи, фото, места) сохраняются при установке новой версии поверх старой — просто установите новый APK.

### Удаление
- Откройте вещь / стеллаж / контейнер / место для редактирования.
- Нажмите значок **🗑️** в правом верхнем углу.
- Вещи и контейнеры не теряются: при удалении стеллажа они становятся «без места», при удалении контейнера — тоже, при удалении места — теряют привязку к месту.

## Технологии
- **Язык**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **БД**: Room (SQLite)
- **Фото**: камера + галерея (PickVisual Media)
- **Минимальная версия Android**: 8.0 (API 26)

---

## Данные
Все данные хранятся на телефоне в базе SQLite (`kladovka.db`). Фото хранятся во внутреннем хранилище приложения. При удалении приложения данные удаляются.

Для резервного копирования: Android автоматически делает бэкап в Google Drive (если включено в настройках телефона).
