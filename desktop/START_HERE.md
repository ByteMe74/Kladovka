# 🚀 Запуск Kladovka Desktop

## Шаг 1: Подготовка

1. Установите **JDK 17** или новее:
   - [Скачать JDK](https://adoptium.net/)
   - Проверьте: `java -version`

2. Убедитесь, что переменная окружения `JAVA_HOME` указывает на JDK

## Шаг 2: Сборка

Откройте командную строку в папке проекта:

```cmd
cd C:\Users\Night\KladovkaProjects\kladovka-desktop
```

Запустите сборку:

```cmd
gradlew.bat build
```

Это займет 5-10 минут при первой сборке.

## Шаг 3: Запуск

После успешной сборки исполняемый файл находится в:

```
C:\Users\Night\KladovkaProjects\kladovka-desktop\build\temp\compose-desktop\build\outputs\apk\debug\app.apk
```

Но для Desktop лучше использовать:

```cmd
gradlew.bat run
```

Приложение откроется автоматически.

## Шаг 4: Использование

1. Нажмите **"Синхронизация"** → введите URL сервера, логин и пароль
2. Нажмите **"Профиль"** → просмотрите информацию об аккаунте
3. Навигация:
   - 📦 **Вещи** - просмотр и редактирование вещей
   - 📚 **Контейнеры** - контейнеры
   - 🗄️ **Стеллажи** - стеллажи
   - 📍 **Места** - места с координатами

## Возможности

✅ Просмотр всех сущностей (вещи, контейнеры, стеллажи, полки, места)  
✅ Поиск по названию и категории  
✅ Синхронизация с сервером  
✅ Экспорт/импорт в JSON  
✅ Общий доступ к складам  
✅ Закрепление важных вещей (звездочка)  
✅ Редактирование и удаление

## Проблемы?

Если что-то не работает:
1. Проверьте `JAVA_HOME`
2. Попробуйте `gradlew.bat clean build`
3. Проверьте консоль на ошибки
